T07-E2-A

A≤50,000时直接读有序文件还是B+树更高效？

Which is likely more efficient for σA≤50,000(R): direct sorted-file access or B+tree?

答案与推理 / Answer and reasoning

课程提供答案；附推导和边界核对 / Course answer with derivation and boundary checks

Read the sorted prefix from the beginning:50,001 rows occupy 5001 pages. The index adds positioning before reading essentially that same prefix, so direct access is slightly preferable. This is a prefix from the known minimum, not an arbitrary small interval.
