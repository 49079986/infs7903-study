T01-E1-i

对R(A B C D)，F={C→D, BC→A}：①求全部候选键和最高范式；②必要时分解到3NF或BCNF。

For R(A B C D), F={C→D, BC→A}: (1) state the candidate key (s) and highest normal form; (2) if necessary, normalise into 3 NF relations or BCNF.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

BC⁺=ABCD；B⁺=B，C⁺=CD，所以BC最小。B与C都无法由其他属性推出，故唯一键BC。C→D是对键真子集的非主属性部分依赖，最高1NF。分ABC、CD；交集C决定CD，故无损。两个原依赖各在一张表内，依赖保持；两表实际上均达BCNF。

BC⁺=ABCD, B⁺=B and C⁺=CD, so BC is minimal. B and C cannot be derived from other attributes, giving the only key BC. C→D is a partial dependency of non prime D on a proper key subset, so only 1 NF. Decompose into ABC, CD. Their intersection C determines CD, making the join lossless; both FDs are locally preserved and both components are actually in BCNF.

T01-E1-ii

对R(A B C D)，F={BC→ABD}：①求全部候选键和最高范式；②必要时分解到3NF或BCNF。

For R(A B C D), F={BC→ABD}: (1) state the candidate key (s) and highest normal form; (2) if necessary, normalise into 3 NF relations or BCNF.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

BC⁺=ABCD，B与C在非平凡右部缺席，故唯一候选键BC。所有给定非平凡依赖的决定项都是超键，最高BCNF，不需分解。BC→B虽可由题目整体写法分解出来，但它是平凡依赖，无需拿来制造违反范式。

BC⁺=ABCD and neither B nor C can be derived from a nontrivial right side, giving only BC. Every nontrivial determinant is a super key, so the relation is BCNF and needs no decomposition. The B component in BC→ABD is trivial and creates no violation.

T01-E1-iii

对R(A B C D)，F={BC→A, CD→AB, A→D}：①求全部候选键和最高范式；②必要时分解到3NF或BCNF。

For R(A B C D), F={BC→A, CD→AB, A→D}: (1) state the candidate key (s) and highest normal form; (2) if necessary, normalise into 3 NF relations or BCNF.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

C必须在键中。BC⁺由BC→A、A→D得到ABCD；CD⁺由CD→AB得到全部；AC⁺先A→D再CD→AB得到全部，三者最小。所有属性都是主属性，所以A→D虽A非超键，仍满足3NF但不满足BCNF。课程分解ABC、AD无损，因为A→AD；CD→AB不局部保持。务必说明无损与依赖保持不同。

Every key must include C. BC⁺ derives A then D; CD⁺ derives AB; AC⁺ derives D then uses CD→AB. BC, CD, AC are all minimal. Every attribute is prime, so A→D satisfies 3 NF despite A not being a super key, but violates BCNF. The course decomposition ABC, AD is lossless because A→AD, but does not locally preserve CD→AB. Separate lossless ness from dependency preservation.

T01-E2

举一个满足2NF但不满足3NF的关系。

Give an example of a relation in 2 NF but not in 3 NF.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

课程例R(ABCD)，F={A→BCD,B→C}。A为唯一键，单属性键没有非主属性的部分依赖，因此2NF。B不是超键、C非主，B→C违反3NF。分ABD、BC，交集B决定BC，且两条FD可局部检查。常见错是例子连2NF都不满足。

The course example is R(ABCD), F={A→BCD, B→C}. A is the only key; its single attribute has no partial dependency of non prime attributes, so 2 NF holds. B is not a super key and C is non prime, so B→C violates 3 NF. Decompose into ABD and BC; intersection B determines BC and the dependencies are locally check able. Ensure the example really satisfies 2 NF.

Ex3共享情境与模式Ex 3 shared context and schema

在线解谜系统允许学生与教师注册。打开题目就写入SOLVED，记录首次DateOpen；未完成时DateSolved为NULL，完成后填写日期。SOLVED只存已打开或已完成的题。PUZZLE的PName唯一，Difficulty为Simple、Advanced、Hard；Solution仅用于系统验证，不能向普通解题者公开。STUDENT与TEACHER是SOLVERS子类，Type取Student或Teacher，Year记录年级。DateOpen不能为NULL。

An online puzzle-solving system lets students and teachers register. Opening a puzzle creates a SOLVED row with its first DateOpen; DateSolved is NULL until successful completion. SOLVED contains only opened or solved puzzles. PUZZLE.PName is unique and Difficulty is Simple, Advanced or Hard. Solution is for system checking and must not be exposed to ordinary solvers. STUDENT and TEACHER subclass SOLVERS, Type is Student or Teacher, Year records study year, and DateOpen is mandatory.

PUZZLE(PName, Difficulty, Solution) -- PK PName
SOLVERS(RegNo, Password, Name, RegistrationDate, Type) -- PK RegNo
STUDENT(RegNo, Year) -- PK/FK RegNo -> SOLVERS
TEACHER(RegNo, Position) -- PK/FK RegNo -> SOLVERS
SOLVED(RegNo, PName, DateOpen, DateSolved) -- PK(RegNo,PName)
-- FKs RegNo -> SOLVERS; PName -> PUZZLE

T01-E3-a

列出谜题，先按难度等级，再按题名排序。

Display a list of Puzzles, ordered by difficulty level and then by Puzzle Name.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

先明确难度是业务等级还是字母序。课程ORDER BY Difficulty会按文本排列Advanced、Hard、Simple；若题意是Simple→Advanced→Hard，应显式CASE映射1、2、3。后用PName确定同等级顺序。

Decide whether difficulty means semantic rank or alphabetic order. The course ORDER BY Difficulty sorts text as Advanced, Hard, Simple. For Simple→Advanced→Hard, map them to 1,2,3 with CASE, then order by PName within each rank.

SELECT PName,Difficulty FROM PUZZLE
ORDER BY CASE Difficulty WHEN 'Simple' THEN 1 WHEN 'Advanced' THEN 2 WHEN 'Hard' THEN 3 END, PName;

T01-E3-b

列出从未被完成过的谜题信息。

List the Puzzle (s) details that have never been solved.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

“从未完成”不等于“从未打开”：存在DateSolved=NULL的记录仍可能合格。寻找不存在非NULL完成日期的匹配。课程用NOT IN在PName非空主键前提下可行，但只输出PName而非所有公开详情；这里用NOT EXISTS保留语义并避免NULL陷阱。

Never solved differs from never opened: rows with NULL DateSolved do not constitute completion. Exclude a puzzle only if a matching non-null completion exists. The course NOT IN works with non-null primary-key PName but returns only names. NOT EXISTS expresses the condition directly and avoids the NULL trap.

SELECT p.PName,p.Difficulty FROM PUZZLE p
WHERE NOT EXISTS (SELECT 1 FROM SOLVED s
 WHERE s.PName=p.PName AND s.DateSolved IS NOT NULL);

找出最早注册的全部解题者姓名及类别。

List the name and corresponding type (Student or Teacher) of the solver (s) who was the first ever to register in this system.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

用MIN取最早日期，再保留相等的所有行，能处理并列。LIMIT 1会漏掉同日/同时间注册的人。课程原SQL缺少MIN右括号，此处修复。

Find the minimum registration date and retain every equal row to handle ties. LIMIT 1 could omit equally early registrants. The course SQL is missing a closing parenthesis for MIN; this version repairs it.

SELECT Name,Type FROM SOLVERS
WHERE RegistrationDate=(SELECT MIN(RegistrationDate) FROM SOLVERS);

T01-E3-d

找出学生完成次数多于教师的谜题。

Find the puzzles that have been solved more times by students than by teachers.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

仅计DateSolved非NULL，按PName分组，将学生和教师计数相比较。零教师完成也能处理；无任何学生完成的题不可能满足“学生更多”。主键(RegNo,PName)意味着同人同题只存一次完成，因此是完成者数量而非尝试次数。

Count only non-null completions, group by PName and compare student versus teacher counts. Zero teacher completions are handled; a puzzle with no student completion cannot qualify. The (RegNo, PName) key means one completion row per person and puzzle, so this counts successful solvers rather than attempts.

SELECT s.PName FROM SOLVED s JOIN SOLVERS v USING(RegNo)
WHERE s.DateSolved IS NOT NULL
GROUP BY s.PName
HAVING COUNT(*) FILTER(WHERE v.Type='Student')
     > COUNT(*) FILTER(WHERE v.Type='Teacher');

T01-E3-e

找出至少完成一道Hard谜题的一年级学生。

Find the “First Year” student (s) who has solved at least one “Hard” Puzzle.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

先把SOLVERS与STUDENT按RegNo连接，Year按题目文字匹配，再EXISTS验证一条已完成Hard记录。EXISTS避免一个学生完成多题重复输出。保留RegNo作为可靠身份。

Join SOLVERS to STUDENT on RegNo, filter the stated Year text and use EXISTS for a completed Hard puzzle. EXISTS avoids duplicate students from multiple matching puzzles. Keep RegNo as reliable identity.

SELECT v.RegNo,v.Name FROM SOLVERS v JOIN STUDENT t USING(RegNo)
WHERE t.Year='First Year' AND v.Type='Student'
AND EXISTS (SELECT 1 FROM SOLVED s JOIN PUZZLE p USING(PName)
 WHERE s.RegNo=v.RegNo AND s.DateSolved IS NOT NULL AND p.Difficulty='Hard');

T01-E3-f

找出至少完成Whiz Kid已完成全部谜题的解题者。

Find the solvers who have solved at least all the puzzles solved by the solver with the name “Whiz Kid”.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

外层必须从所有SOLVERS出发。寻找Whiz Kid的任一已完成题，若候选没有已完成该题就是反例；不存在反例才保留。候选的DateSolved也必须非NULL，“打开过”不等于“做完”。若目标集合为空，所有候选符合。Name未声明唯一；此SQL将同名Whiz Kid的已完成题取并集，如题目要求某个唯一人，需补充RegNo。原答案RegoNo/Solver拼写与候选完成条件有问题，配套PPT还遗漏目标完成日期。

Start with every SOLVERS row. Look for a completed Whiz Kid puzzle that the candidate has not completed; retain candidates with no counterexample. Candidate DateSolved must also be non-null: opened is not solved. An empty target set qualifies everyone. Name is not declared unique; this SQL unions completed puzzles of all matching names. Supply a RegNo if one specific person is intended. The reference answer has RegoNo/Solver typos and candidate-completion omissions; the companion PPT also omits the target completion filter.

SELECT v.RegNo,v.Name FROM SOLVERS v
WHERE NOT EXISTS (
 SELECT 1 FROM SOLVED w JOIN SOLVERS target ON target.RegNo=w.RegNo
 WHERE target.Name='Whiz Kid' AND w.DateSolved IS NOT NULL
 AND NOT EXISTS (SELECT 1 FROM SOLVED mine
  WHERE mine.RegNo=v.RegNo AND mine.PName=w.PName
    AND mine.DateSolved IS NOT NULL)
);
