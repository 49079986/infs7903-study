T10-E2-A

哪些调度冲突可串行化？

Which schedules are conflict serialisable?

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；附逐步推导与更正 / Course answer with stepwise derivation and corrections

S1与S2在A、B上只有T1→T2，均可串行化，S1还本来就是串行。S3在A为T1→T2、B为T2→T1，有环。S4在A有T2→T1；B上r1(B)先w2(B)给T1→T2，同时w2(B)先w1(B)给T2→T1，有环。这里检验冲突可串行化，不涉及提交恢复性。

S1/S2 have only T1→T2 on A and B, and are conflict-serialisable; S1 is already serial. S3 has T1→T2 on A and T2→T1 on B, a cycle. S4 has T2→T1 on A; on B, r1 before w2 gives T1→T2 and w2 before w1 gives T2→T1, a cycle. This tests conflicts rather than commit recoverability.

Ex5程序顺序Ex 5 program order

T1:r1(Y);Y:=Y-K;w1(Y);r1(X);X:=X+K;w1(X);c1
T2:r2(X);X:=X+J;w2(X);c2

下面省略算术行，但读写与提交顺序保留；算术应放在相应read与write之间。分类可以重叠，不要求每例仅满足一个标签。Serial本身不可能是交错的，原题统一称interleaved时存在措辞张力。

T10-E6-C

S3中T3写5、T4盲写6，T3回滚会丢6。它是否无级联，怎样修？

S3:r3(X);w3(X);w4(X);a3;c4. T3 writes 5, T4 overwrites 6. Is it cascadeless? Repair the lost 6 problem.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；附逐步推导与更正 / Course answer with stepwise derivation and corrections

无级联，因为没有别的事务读未提交写；但不严格，因为T4写了T3未完成的数据项。把a3放w4前，先撤销T3，再写6，避免Undo旧值覆盖T4。不能把“没有脏读”当成“没有恢复问题”。

It is cascadeless because no other transaction reads an uncommitted write, but not strict because T4 overwrites an unfinished writer. Movea 3 before w4: undo T3 first, then write 6. Do not equate absence of dirty reads with absence of recovery hazards.

r3(X);w3(X);a3;w4(X);c4;
