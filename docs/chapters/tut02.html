T02-E1

简述关系数据库为什么需要视图。

Briefly discuss: why do we need views in relational databases?

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

视图用稳定逻辑接口隐藏表结构与连接细节，让同一事实按不同用户需求呈现，并可结合权限隐藏列或限定行。普通视图只保存定义，不必复制数据；物化视图另讨论存储、维护与新鲜度。课程答案仅指向教材，本段为课程概念整合。

Views hide schema and join details behind stable logical interfaces, present the same facts for different users and can restrict rows or columns with privileges. An ordinary view stores its definition without duplicating data; materialised views introduce separate storage, maintenance and freshness decisions. The course answer gives reading references; this is an integrated explanation.

T02-E2

视图创建需要权限且有所有者。简述如何用视图做授权控制。

Whoever creates a view in DBMS must be authorised and the view has ownership. Briefly describe how views can be used for security control such as authority control.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

DBA按角色建立只显示所需数据的视图，GRANT授予相应访问，REVOKE收回权限；同时检查基表访问和所有者权限，防止绕过视图。身份认证回答“是谁”，授权回答“能做什么”；仅创建视图而仍把基表全部授权给用户，不能达成预期隔离。

The DBA creates role-specific views exposing required data, grants suitable access and revokes it when needed. Review base access and ownership to prevent bypass. Authentication establishes identity; authorisation establishes permitted actions. Creating a view while retaining unrestricted base privileges does not achieve the intended restriction.

T02-E4-E

查超过20名员工的部门号、员工数和平均工资。

Find the average salary for each department with more than 20 employees, showing department id, employee count and average salary.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；下文含教学推导与必要更正 / Course answer with teaching derivation and necessary corrections

假设Works主键(eid,did)，每员工部门组合唯一，连接后按did分组，HAVING COUNT(*)>20。pcttime不作为平均权重，因为题目没要求按工时加权。

Assume Works has unique (eid, did). Join, group by did and retain COUNT(*)>20. Do not weight by pcttime unless requested.

SELECT w.did,COUNT(*) AS employee_count,AVG(e.salary) AS average_salary
FROM Works w JOIN Emp e ON e.eid=w.eid
GROUP BY w.did HAVING COUNT(*)>20;

DELETE FROM P WHERE weight>14 AND (weight*15)<10;
