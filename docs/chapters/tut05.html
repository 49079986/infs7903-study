T05-E1

关系数据库怎样保存元数据和业务数据？

In a relational database system, how are metadata and data stored?

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；附教学推导、更正或明确假设 / Course answer with derivation, corrections or explicit assumptions

元数据存系统目录，如模式、约束、索引定义与统计；业务值存在数据文件页中，索引节点也有物理文件页。两者都二进制存储。访问SQL先解析名称与权限，再按文件/索引定位具体页；不是目录替代业务数据。

Metadata resides in the system catalogue, including schemas, constraints, index definitions and statistics. Business values occupy data-file pages and index nodes have physical pages too. Both use binary representation. SQL resolves names and privileges before using files/indexes to locate pages; catalogue metadata does not replace business data.

T05-E3

讨论排队延迟、热点及不同文件的处理策略。

Discuss queueing delay and hotspots in disk I/O and strategies for different file types.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；附教学推导、更正或明确假设 / Course answer with derivation, corrections or explicit assumptions

排队是请求量超过服务速度形成等待，热点是访问集中。缓存、预取和批量顺序读减少设备工作；heap目录找空位减少链表遍历，ordered范围利用局部性，hash需均匀分桶并控制溢出。多盘或读副本可分摊读取，写复制还要保持一致。增加空间可换时间但不是无成本。

Queueing occurs when demand exceeds service rate; hotspots concentrate access. Caching, pre fetching and sequential batches reduce device work. Heap directories reduce free-space travers al, ordered ranges exploit locality, and hash layouts need even buckets with controlled overflow. Multiple disks/read replicas distribute reads, while replicated writes require consistency. Trading space for time still has costs.

T05-E4

比较定长与变长记录的存储和访问。

Compare fixed-length and variable-length records in storage and access.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

课程提供答案；附教学推导、更正或明确假设 / Course answer with derivation, corrections or explicit assumptions

定长字段偏移直接计算、修改简单，代价是最大长度填充和块尾碎片。变长减少字段填充但需长度/分隔/偏移元数据，增长可能移动；顺序编码定位后字段需跳过前字段，偏移目录可改善。两者都要按具体跨块规则算容量，变长并不保证总开销更小。

Fixed length permits direct offsets and simple modification but wastes padding and block tails. Variable length reduces field padding but needs length/delimiter/offset metadata and may move on growth. Sequential encoding traverses preceding fields, while offset directories help. Compute capacity under the actual spanning rule; variable length need not minimise total bytes.
