前置知识补充：分组最高项与窗口函数Prerequisite supplement: top-per-group and windows

窗口函数（window function）在一组相关行上计算，同时保留每行身份；GROUP BY则通常把一组压为一行。每地区最高销售门店可先按地区、门店汇总，再ROW_NUMBER() OVER(PARTITION BY region ORDER BY total DESC,shop)编号，外层保留rn=1。RANK会把并列最高都标1；若只要一店，ROW_NUMBER需明确次排序以保证可重复。

A window function computes across related rows while preserving each row’s identity; GROUP BY normally collapses groups. Top sales per region can first aggregate by region/shop, then useROW_NUMBER()OVER(PARTITION BY region ORDER BY total DESC, shop)and filter rn=1 outside. RANK labels tied winners 1; if exactly one winner is required, ROW_NUMBERneeds a deterministic tie-breaker.

-- Author-created example / 自编例子
WITH sales(region,shop,amount) AS (
 VALUES ('North','A',10),('North','B',10),('South','C',7)
), ranked AS (
 SELECT region,shop,amount,
 ROW_NUMBER() OVER(PARTITION BY region ORDER BY amount DESC,shop) AS rn
 FROM sales
)
SELECT region,shop,amount FROM ranked WHERE rn=1 ORDER BY region;

该自编例预期North选A、South选C；若只按amount排序，North两店并列时结果不唯一。窗口结果rn通常不能在同一层WHERE中使用，所以再套CTE/子查询。数据来自VALUES，读者可独立复算；本教材不把这个结果冒称FleetDB的真实最忙站点。

The example expects North/A and South/C. Without the shop tie-breaker, the North winner is undetermined. The computed rn usually needs an outer CTE/sub query filter. It is a self-contained VALUES example, not a claim about FleetDB ’s actual busiest station.

前置知识补充：递归CTE遍历层级Prerequisite supplement: recursive CTEs traverse hierarchies

公共表表达式（common table expression，CTE）给查询中的中间结果命名，类似RA临时关系。递归CTE包含起始项和递归项：先生成根，再把上一轮发现的节点扩展到孩子，直到没有新行。对树形赞助关系，可以从parent为空的根向下传播root；只做COALESCE(parent,id)只看一跳，会把孙节点归到中间节点。

A common table expression (CTE)names an intermediate query result, like an RA temporary relation. A recursive CTE has an initial term and recursive term: start at roots, expand the preceding round to children, and stop when no new rows appear. In a tree, propagate root identifiers down from NULL parents. COALESCE(parent, id)examines only one edge and mis assigns grandchildren to intermediates.

-- Author-created hierarchy / 自编层级
WITH RECURSIVE org(id,parent) AS (
 VALUES ('R',NULL::text),('T','R'),('S','T'),('U','R')
), tree(id,root,depth) AS (
 SELECT id,id,0 FROM org WHERE parent IS NULL
 UNION ALL
 SELECT c.id,t.root,t.depth+1 FROM org c JOIN tree t ON c.parent=t.id
)
SELECT * FROM tree ORDER BY depth,id;

逐轮得到R/R/0；T/R/1与U/R/1；S/R/2。终止依赖数据形成有限无环树；若存在环或无根分量，要检查循环并定义处理策略，不能指望UNION ALL自动去重。先建“每成员属于哪个根”的唯一映射，再聚合费用，避免在递归每层重复计同一笔费用。

Rounds yield R/R/0; T/R/1 and U/R/1; then S/R/2. Termination assumes a finite a cyclic rooted structure. Cycles or rootless components require explicit handling; UNION ALL does not de duplicate automatically. Create one member-to-root mapping before aggregating charges to avoid counting a charge once per recursive level.

PostgreSQL 17 · WITH and recursive queries

反连接、表达式与复合索引的迁移Transferring anti-joins, expressions and composite indexes

反连接（anti-join）寻找没有匹配的左行。NOT EXISTS与LEFT JOIN…WHERE右键IS NULL可等价，前提是右侧测试列能可靠表示匹配，且筛选“Collect”写在ON里保留无匹配左行。若放WHERE event_type=Collect，会先删掉NULL扩展行，破坏“从未Collect”的需求。优化器可能把两种SQL改成相同物理anti join，需看实际计划而非SQL表面。

An anti-join finds left rows without matches. NOT EXISTS and LEFT JOIN…WHEREright_keyIS NULL can be equivalent if the tested right key reliably indicates a match. The Collect predicate belongs in ON to retain unmatched left rows. Putting it in WHERE removes NULL-extended rows and breaks never-Collect semantics. The optimiser may turn both forms into the same physical anti join; inspect the actual plan.

复合B-tree索引(a,b)按先a后b排序，因此a等值加b范围常可缩小连续区间。只筛b、或a范围覆盖大多数行时，未必同样有效。表达式索引按f(email)排序，完整email唯一索引按完整地址排序，不能直接按域后缀等值定位。域需大小写规范化，并保证查询与索引表达式对应；汇总全体成员仍需读取很多值，稀有域查找则可能显著减少访问。

A composite B-tree (a, b)orders by a and then b, so equality on a and range on b can identify a narrow contiguous interval. Filtering only bor matching most a values need not benefit equally. An expression index orders f (email), while a unique email index orders entire addresses, not domain suffixes. Normalise case and match expressions. Afull-domain aggregation still reads many values; rare-domain lookup can reduce access substantially.

快照与触发器：为什么先查再写会失效Snapshots and triggers: why check-then-write can fail

来源 / Source: A2/a2-2026-v1.pdf · PDF p. 7-8（原资料留在本地版） · 本地逐页图文 / Local pages

多版本并发控制（multiversion concurrency control，MVCC）让普通SELECT按快照看已提交版本。PostgreSQL默认READ COMMITTED为每条语句取新快照；同事务两次查询之间，其他事务提交可改变第二次所见。普通快照读通常不挡普通写，读到某行并不预留它；SELECT FOR UPDATE是显式加锁的另一个操作，DDL等也有不同锁。

MVCC lets ordinary SELECT read committed versions through snapshots. PostgreSQL’s default READ COMMITTED takes a fresh snapshot per statement, so another commit between statements can change the second result. Ordinary snapshot reads normally do not block ordinary writes and do not reserve rows. SELECT FOR UPDATE explicitly locks; DDL has other locking behaviour.

自编库存例：库存1，S1查1但不锁；S2查1后扣到0并提交；S1仍按先前结论尝试购买，新的语句/触发器可能看到0。旧查询正确不代表后来条件仍真。可把检查与修改合为带条件UPDATE…WHERE stock>0并检查影响行数，或锁同一资源行并在锁后重查；使用更强隔离也要处理冲突重试。

In a stock example, S1 reads 1 without locking; S2 reads 1, decrements to 0 and commits; S1 then acts on its earlier conclusion, but a new statement/trigger can see 0. A correct earlier query does not keep a condition true. Combine checking with conditional UPDATE…WHERE stock>0 and verify affected rows, or lock the resource and recheck. Stronger isolation also requires conflict retries.

PostgreSQL 17 · Transaction isolation

怎样形成可以复现的实验解释Producing a reproducible experimental explanation

用固定次序记录：数据准备版本与行数，当前索引，ANALYZE时间，所有SET值，完整SQL，完整计划，估计/实际行数与loops、耗时、观察结论。两会话实验每步注明连接1/2和阻塞点；错误后先确认事务是否仍可继续，再ROLLBACK清理。不要把某次运行的EXPLAIN估计行数抄成真实结果。

Record preparation version and row counts, indexes, ANALYZE, all SET values, SQL, full plans, estimated/actual rows, loops, timing and interpretation in a fixed order. Label session 1/2 and blocking points in concurrency experiments. After errors, check transaction state and ROLLBACK for cleanup. Never report estimated EXPLAIN rows as observed results.

练习迁移时改变一个条件：稀有值换常见值、等值换范围、单层父关系换三层、普通视图换物化视图，先预测再跑实验。预测和观测有分歧时，检查输入、统计、表达式匹配、缓存及会话设置，而不是改写观测来迎合理论。

For transfer practice, change one condition: rare to common, equality to range, one parent level to three, or ordinary to materialised view. Predict before executing. If observation differs, inspect inputs, statistics, expression matching, caching and session settings rather than altering evidence to fit theory.

总结与自测Summary and self-check

综合问题常同时需要语义与机制：找对根账户是逻辑，访问费用是优化；用触发器拒绝非法状态是完整性，两个会话争同资源是并发。把一题分成这些可以解释的小问题，再组合回完整方案，才具备迁移能力。

Integrated problems combine semantics and mechanisms: root-account identification is logic, access expense is optimisation; trigger rejection concerns integrity, while two sessions competing for a resource concern concurrency. Decompose the task into explain able pieces and recombine them to develop transfer ability.
