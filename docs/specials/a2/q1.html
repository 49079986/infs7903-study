TASK SUMMARY + LINE GUIDE
中文题意 / Task in Chinese

（1分）每种body type选取Collect次数最多的单一站点，建视图输出类型、站名、次数并降序。

(1 marks) Create V_BUSIEST_BAYS: for each body type, one station with most collections; report type, station, count ordered descending.

解答、逐行代码与实测依据 / Solution, line guide and evidence

先按 body_type 和 station 汇总 Collect 次数，再在每种 body type 内用 ROW_NUMBER 排名。只保留 rn = 1，恰好选出一个站点；station_id 是次数相同时的确定性规则。最后按获胜次数降序排列。

The first CTE counts Collect events for each body type and station. ROW_NUMBER partitions those counts by body type and picks the largest count; station_id resolves ties deterministically so exactly one station is returned per represented body type. The final ORDER BY puts the largest winner first.

BOOKING_EVENTS 没有事件发生站点字段，所以这里使用 VEHICLES 记录的站点。这是现有 schema 能支持的站点语义。

The schema records a station on VEHICLES, rather than on BOOKING_EVENTS. The station reported is therefore the vehicle's recorded station, which is the location available in the supplied schema.

A2_1.1.1.sql
-- INFS7903 Assignment 2 | Public teaching edition
CREATE VIEW V_BUSIEST_BAYS AS
WITH collection_counts AS (
    SELECT m.body_type, s.station_id, s.station_name,
           COUNT(*) AS collections
    FROM BOOKING_EVENTS e
    JOIN VEHICLES v ON v.vehicle_id = e.vehicle_id
    JOIN MODELS m ON m.model_code = v.model_code
    JOIN STATIONS s ON s.station_id = v.station_id
    WHERE e.event_type = 'Collect'
    GROUP BY m.body_type, s.station_id, s.station_name
), ranked_stations AS (
    SELECT *, ROW_NUMBER() OVER (
        PARTITION BY body_type
        ORDER BY collections DESC, station_id
    ) AS rn
    FROM collection_counts
)
SELECT body_type, station_name, collections
FROM ranked_stations
WHERE rn = 1
ORDER BY collections DESC, body_type;

（1.5分）建视图列2026年1月1日至6月30日费用最高的十个最终根账户及其总金额。

(1.5 marks) Create V_ACCOUNT_LIABILITY with the ten root accounts liable for the largest charges dated 1 Jan–30 Jun 2026 inclusive.

解答、逐行代码与实测依据 / Solution, line guide and evidence

递归基础层把无 sponsor 的账号映射到自己；递归层让 child 继承 parent 的根账号。每名成员只映射到最终 root，因此每条收费事件只计一次，不在中间 sponsor 上重复累加。

The recursive seed maps each unsponsored account to itself. Each recursive step maps a sponsored child to the same root account as its parent, so every member in the supplied sponsorship forest maps to exactly one ultimately liable account. Joining charges to this mapping bills personal charges and every level of sponsored charges to the root, without counting an event at several intermediate accounts.

只计 Return 和 Incident 的收费。日期范围为 2026-01-01（含）到 2026-07-01（不含），覆盖 6 月 30 日全天；按金额降序取前 10。另一套独立的向上递归校验得到同样结果。

Only Return fares and Incident damage charges are included. The half-open timestamp range from 2026-01-01 up to, but excluding, 2026-07-01 includes all of 30 June. Totals are sorted descending, with member_id as a deterministic tie-breaker, and limited to ten accounts. The result is shown in Q1.3 Query A. An independent upward traversal produced the same ten rows.

A2_1.2.sql
-- INFS7903 Assignment 2 | Public teaching edition
CREATE VIEW V_ACCOUNT_LIABILITY AS
WITH RECURSIVE account_tree AS (
    SELECT member_id, member_id AS account_id
    FROM MEMBERS
    WHERE sponsor_id IS NULL
    UNION ALL
    SELECT child.member_id, parent.account_id
    FROM MEMBERS child
    JOIN account_tree parent ON child.sponsor_id = parent.member_id
)
SELECT root.member_id, root.member_name,
       SUM(e.amount) AS total_amount
FROM account_tree t
JOIN MEMBERS root ON root.member_id = t.account_id
JOIN BOOKING_EVENTS e ON e.member_id = t.member_id
WHERE e.event_type IN ('Return', 'Incident')
  AND e.event_time >= TIMESTAMP '2026-01-01'
  AND e.event_time <  TIMESTAMP '2026-07-01'
GROUP BY root.member_id, root.member_name
ORDER BY total_amount DESC, root.member_id
LIMIT 10;
