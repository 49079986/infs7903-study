每题固定这样学A consistent way to work through each part

  1. 先读题意：先说明题目需要什么输入与输出；课程原文从授权课程渠道核对。
  2. 再看中文题意：明确输出列、筛选范围、排序、并发连接与提交顺序。
  3. 打开完整代码：代码与已实测脚本逐字符对应，可复制或下载。
  4. 逐行追踪：字段来自哪张表、别名是什么、条件在哪一层生效、括号关闭哪段逻辑。
  5. 最后对照证据：阅读 actual rows、cost、时间或完整错误，再勾选“能够解释并复现”。
