Q4.1.1

TASK SUMMARY + LINE GUIDE
中文题意 / Task in Chinese

（2分）会话1开始事务，找最新事件为Return的车，保持未提交。

(2 marks) Session 1: BEGIN and find a vehicle whose latest event is Return; leave transaction open.

解答、逐行代码与实测依据 / Solution, line guide and evidence

连接 1 在 READ COMMITTED 下 BEGIN，查得 VEH-0001 的最新事件是 Return 194486，时间为 2026-06-27 11:05:11。先对所有事件按 event_time DESC、event_id DESC 取最新，再检查 Return；不能先过滤 Return 再取最新。

Connection 1 begins a READ COMMITTED transaction and returns VEH-0001 with latest event 194486, a Return at 2026-06-27 11:05:11. The lateral subquery first selects the latest event across all event types, using event_id to break timestamp ties. Only after that does the outer query test for Return. An older Return cannot incorrectly qualify a vehicle whose latest state is Reserve, Collect or Incident.

下一步必须在另一连接重查同一辆车，连接 1 此时保持事务打开。这个普通读取没有预留车辆。

The selected vehicle is kept fixed for the same availability check in connection 2. Connection 1 stays open after this step.

A2_4.1.1.sql
-- INFS7903 Assignment 2 | Public teaching edition
-- connection 1
BEGIN;
SHOW transaction_isolation;
SELECT v.vehicle_id, latest.event_id,
       latest.event_type, latest.event_time
FROM VEHICLES v
CROSS JOIN LATERAL (
    SELECT e.event_id, e.event_type, e.event_time
    FROM BOOKING_EVENTS e
    WHERE e.vehicle_id = v.vehicle_id
    ORDER BY e.event_time DESC, e.event_id DESC
    LIMIT 1
) latest
WHERE v.vehicle_id = 'VEH-0001'
  AND latest.event_type = 'Return';
-- Keep this transaction open. Run 4.1.2 in connection 2.

（0.5分）会话2重查同车，给另一成员插三天后Reserve并提交。

(0.5 marks) Session 2: BEGIN, recheck same vehicle, Reserve for another member in three days, COMMIT.

解答、逐行代码与实测依据 / Solution, line guide and evidence

连接 2 同样是 READ COMMITTED，也看到最新 Return。它为 member 2 插入三天后的 Reserve 并成功 COMMIT；连接 1 仍开着的普通 SELECT 并未阻止此次插入。

Q4.1.3

TASK SUMMARY + LINE GUIDE
中文题意 / Task in Chinese

（1分）会话1尝试现在为另一成员Collect后提交，报告结果事件。

(1 marks) Session 1: attempt Collect for a different member at now (), then COMMIT; report resulting events.

解答、逐行代码与实测依据 / Solution, line guide and evidence

连接 2 提交后，连接 1 为 member 1 尝试现在 Collect，触发器报错：Vehicle VEH-0001 is reserved by member 2。事务进入失败状态，COMMIT 的结果是 ROLLBACK，没有新增 Collect。

Connection 1 attempts a present-time Collect for member 1 after connection 2 commits. BI_COLLECT rejects it with ERROR: Vehicle VEH-0001 is reserved by member 2. The transaction is then failed, so the attempted COMMIT produces ROLLBACK. No new Collect is stored.

最终最新事件是 Reserve 196442，其后是历史 Return 194486 和历史 Collect 194367。本次两个竞争新增事件中只有 Reserve 留下；Q1.3 的 Incident 是更早的独立事件。失败插入可能消耗 serial 值，序列间隙不等于存在已提交记录。

The verification query shows Reserve event 196442 as the latest event, ahead of historical Return 194486 and historical Collect 194367. Of the two competing new events in this experiment, only the Reserve survives. The Incident from Q1.3 remains a separate older historical event. Sequence allocation can leave a gap for the rejected Collect; a consumed serial value does not prove that a row committed.
