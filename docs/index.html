A2 / 11 INTERACTIVE LABS / LEARN FROM ZERO

A2 专项 · 从零开始，动手读懂 SQL

从四条事件记录开始，逐步播放、修改参数、预测结果，再跳回对应代码。用 11 个教学实验理解排名、递归、索引、快照和死锁，最后在练习室用自己的话向老师讲清楚。

Start with four event records: step through, change a parameter and predict the result, then follow the matching code. Eleven teaching labs build up to ranking, recursion, indexes, snapshots and deadlocks; rehearse your explanation in the tutor room.
