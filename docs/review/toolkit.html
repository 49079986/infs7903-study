公式与方法速查Formula and method sheet

以下公式都带模型假设。符号B为块字节数，R为定长记录字节数，r为记录数，b为数据块数，P为指针大小，V为索引键大小，f为扇出，N/M为记录数。ceil为向上取整，floor为向下取整。不要把字节、块、记录或毫秒混加。

Every formula below has model assumptions. B is bytes per block, R bytes per fixed-length record, r records, b data blocks, P pointer size, V index-key size, f fan-out, and N/M input records. ceil rounds up and floor rounds down. Never add unlike units such as bytes, blocks, records and milliseconds.

对象 / Object公式或步骤 / Formula or procedure条件与解释 / Conditions and interpretation

闭包

Closure

X⁺ starts X; repeatedly add Y if A→Y and A⊆X⁺.

达到不动点；X⁺=全部属性仅证明超键，最小化后才是候选键。

Reach a fixed point; full closure proves a super key, not minimality.

3NF / BCNFEvery nontrivial X→A: X superkey OR A prime / X superkey.

检查蕴含依赖；主属性属于某个候选键。

Consider implied FDs; prime means in some candidate key.

块与浪费

Blocks and waste

bfr=floor(B/R); b=ceil(r/bfr); waste=B−bfr·R

非跨块、定长；最后一页需单独数实际记录。

Unspanned fixed records; count the final partial page separately.

磁盘时间

Disk time

Trot=60000/rpm ms; rd≈Trot/2; btt=B/tr; random=s+rd+btt

一次随机访问含寻道与等待；连续k块通常s+rd+k·btt。

A random access includes seeking/waiting; contiguous k blocks usually cost s+rd+k·btt.

有序二分

Ordered binary search

Approx ceil(log₂ b) probes in the course model.

边界与精确算法可差一次；记录结果不存在的处理。

Boundary cases and exact algorithms may differ by one probe; handle absence.

索引

Index

entry=V+P; f=floor(B/(V+P)); level_next=ceil(level/f)

稀疏主索引起始条目b，稠密二级索引起始条目r；逐层算。

Start with b sparse or r dense entries; count every level.

B+树

B+ tree

Find leaf → insert sorted → split → propagate separator → split root if necessary.

先写清order、最小占用与MIN-RIGHT/MAX-LEFT惯例。

State order, occupancy and separator convention first.

选择率

Selectivity

output≈s·N

0≤s≤1；相关谓词不能随意当独立相乘。

Selectivity lies in [0,1]; correlated predicates need not multiply independently.

课内连接成本

Course join cost

P(N)=N(1+log₂N); J(N,M)=P(N)+P(M); S(N)=N

本课简化比较单位，并非PostgreSQL计划cost或毫秒。

Course comparison units, not PostgreSQL cost or milliseconds.

基数

Cardinality

|R×S|=|R|·|S|; valid non-null FK join to unique key yields |R|.

后式需完整引用和唯一父键；输出行数不是连接工作量。

The FK formula needs valid references and uniqueness; output size is not work.

冲突图

Precedence graph

Different transactions + same item + at least one write → directed order edge.

无环⇔冲突可串行化；拓扑序是等价串行顺序。

A cyclic iff conflict-serialisable; topological orders give equivalent serial orders.

恢复性质

Recovery properties

Strict ⊆ Cascadeless ⊆ Recoverable

分别看未完成写能否被读/写、read-from与提交顺序；不是可串行化的包含链。

Examine unfinished writes, read-from and commit order separately from serialisability.

时间戳

Timestamp ordering

Read: TS≥WTS; write: TS≥RTS and TS≥WTS.

通过后RTS=max(RTS,TS)或WTS=TS；Thomas对过时写另作忽略。

Update RTS/WTS after acceptance; Thomas separately ignores obsolete writes.

恢复

Recovery

Steal⇒Undo; No-force⇒Redo; WAL before data-page flush.

活跃事务的检查点前记录仍可能需要；提交不等于已刷数据页。

Pre-checkpoint records of active transactions may still matter; commit is not a data-page flush.

先发生冲突给串行顺序约束；等待者指向持锁者检测死锁。

Dirty read

Deadlock

饥饿

互等形成循环，对比某事务一直得不到推进；无死锁未必无饥饿。

常见错误与纠正动作Common errors and corrective actions

闭包算全就宣布候选键。 纠正：逐个删除属性测试最小性。

Declaring a candidate key immediately after full closure. Correction: Remove each attribute and retest minimality.

按样例中没重复推断普遍FD。 纠正：区分约束假设、反例与样例支持。

Inferring a universal FD from a small duplicate-free sample. Correction: Separate an assumed constraint, a counterexample and sample support.

NOT IN忽略NULL。 纠正：先证明子查询无NULL，或用NOT EXISTS。

Ignoring NULL in NOT IN. Correction: Prove non-null ness or use NOT EXISTS.

聚合视图直接写回。 纠正：解释底层修改为何不唯一。

Updating an aggregate view automatically. Correction: Explain why the base modification is ambiguous.

跨行规则写入普通CHECK。 纠正：选择触发器并分析并发写路径。

Putting cross-row rules in an ordinary CHECK. Correction: Choose triggers and analyse concurrent write paths.

计算中间结果时提前取整。 纠正：保留精度，只在离散容量边界取整。

Rounding intermediate calculations prematurely. Correction: Retain precision and round at discrete capacity boundaries.

B+树混用分隔规则。 纠正：先写等值走向，每步核对叶链与边界。

Mixing B+ separator conventions. Correction: State equality routing and verify leaf order and separators.

把索引存在当必选。 纠正：检查选择率、回表、统计与全扫费用。

Assuming an existing index must be chosen. Correction: Inspect selectivity, heap access, statistics and scan expense.

关系除法忘记空目标。 纠正：明确候选全集与全称量词的空真。

Forgetting an empty divisor target. Correction: Define the candidate universe and vacuous truth.

图有环但不列证据。 纠正：给每条边写数据项与先后操作。

Claiming a cycle without operation witnesses. Correction: Give the item and ordered operations for each edge.

把abort当commit。 纠正：沿read-from检查读者是否仍可提交。

Treating abort as commit. Correction: Follow read-from dependencies before permitting reader commit.

检查点前日志一律跳过。 纠正：检查当时活跃事务和实际页面持久性。

Discarding all pre-checkpoint log records. Correction: Inspect active transactions and actual page durability.

抄示例耗时作为自己结果。 纠正：记录实际实验；未运行明确标推导。

Reporting example timings as personal observations. Correction: Retain actual evidence and label unrun reasoning.

综合自测：自编题与参考解析Integrated self-test: author-created questions and solutions

I01

R(A,B,C,D)，F={A→B,B→C,CD→A}。求键及最高范式。

R(A, B, C, D), F={A→B, B→C, CD→A}. Find keys and highest normal form.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

自编练习；参考解析 / Author-created exercise; reference solution

D不出现在右部，必须在键中。AD⁺先A→B→C得到全部；BD⁺由B→C再CD→A得到全部；CD⁺由CD→A→B得到全部，三者均最小。所有属性都在某个候选键内，所以为3NF；A→B的A非超键，非BCNF。

D never occurs on a right side and must be in every key. AD derives B then C; BD derives C then A; CD derives A then B. AD, BD and CD are minimal. Every attribute is prime, so 3 NF holds; A→B has a non-super key determinant, so BCNF fails.
