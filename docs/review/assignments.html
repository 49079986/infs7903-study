A1-Q1

（3分）写一个命名为CK_SHIFT_TIMES的约束：结束严格晚于开始，时长不超过8小时。

(3 marks) Write one named CK_SHIFT_TIMES constraint enforcing ends strictly after starts and duration at most 8 hours.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

根据课程内容整理的解题指南；未提供官方实现 / Course-derived solution guide; no official implementation supplied

同一行两条件用AND。测试0小时、负数、恰8小时及8小时加1秒；若时间列可NULL，CHECK本身不排除UNKNOWN，结合原模式NOT NULL。对应第4章CHECK。

Combine the two same-row conditions with AND. Test zero, negative duration, exactly eight hours and eight hours plus one second. CHECK alone permits UNKNOWN, so use the schema’s NOT NULL requirements. See Chapter 4.

A1-Q2.1

（4分）创建BI_SIGNUP/UDF_BI_SIGNUP：新增报名须达到班次开始日最低年龄，非取消报名不得超容量。

(4 marks) Create BI_SIGNUP/UDF_BI_SIGNUP to enforce age at shift start and non-cancelled capacity on a new signup.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

根据课程内容整理的解题指南；未提供官方实现 / Course-derived solution guide; no official implementation supplied

先由shift找role与开始日，再由volunteer生日判断周年边界；按同shift计非Cancelled，加入本次有效占位后不能超capacity。Cancelled是否占位必须按题目定义；并发必须串行化同班次容量检查。生日等于开始日可，晚一天不可。

Obtain the role and start date from the shift, then test the birthday anniversary boundary. Count non-Cancelled signups for that shift and include the new occupied place where applicable. Follow the given cancellation semantics and serialize capacity checks for the same shift under concurrency. The birthday on the shift date qualifies; the following day does not.

A1-Q2.2

（4分）创建更新触发器与函数，禁止更换志愿者或班次；状态只允许不变，或Booked转Attended/NoShow/Cancelled。

(4 marks) Create BU_SIGNUP/UDF_BU_SIGNUP enforcing immutable volunteer_id/shift_ref and only unchanged status or Booked→Attended/No Show/Cancelled.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

根据课程内容整理的解题指南；未提供官方实现 / Course-derived solution guide; no official implementation supplied

比较OLD与NEW引用，状态按有向边判断而非仅检查枚举。终态到终态也不允许，终态保持不变允许。使用IS DISTINCT FROM可稳健比较NULL，但原列非空时普通比较也有前提。列出所有状态对建立测试矩阵。

Compare OLD/NEW references and test directed state transitions, not merely membership in an enumeration. Final-to-final changes are prohibited, while an unchanged final state is permitted. IS DISTINCT FROM handles NULL robustly; ordinary comparison relies on non-null columns. Build a full transition test matrix.

A1-Q3.2

（4分）建BI_SHIFT_REF/UDF_BI_SHIFT_REF，生成YYMMDD-两字母班次编号。

(4 marks) Create BI_SHIFT_REF/UDF_BI_SHIFT_REF generating YY MM DD plus a two-letter code from n.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

根据课程内容整理的解题指南；未提供官方实现 / Course-derived solution guide; no official implementation supplied

日期取starts_at；n/26用整数商，再mod26；第二字母n mod26。n=3000得到115、11=L、10=K，所以260914-LK。每676个n后缀重现，同日不能无限保证唯一，主键仍需检查。

Use starts_at for the date. Integer division n/26 gives 115 at n=3000; 115 mod 26=11 maps to L, and 3000 mod 26=10 maps to K, producing 260914-LK. Suffixes repeat every 676 values, so same-day uniqueness is bounded and the key must still be enforced.

A1-Q4.1

（5分）用AIUD_CREDITS及函数维护credits，覆盖报名插入、更新、删除，只累计Attended时长×角色费率。

(5 marks) Maintain VOLUNTEERS.credits as total Attended hours×role rate for INSERT, UPDATE, DELETE using AIUD_CREDITS/UDF_AIUD_CREDITS.

先独立尝试：写出条件、方法和理由，再展开。 / Try first: write the conditions, method and reasons before revealing the solution.

答案与推理 / Answer and reasoning

根据课程内容整理的解题指南；未提供官方实现 / Course-derived solution guide; no official implementation supplied

INSERT加NEW有效贡献；DELETE减OLD有效贡献；UPDATE移除OLD再加NEW，或重算受影响者总和。空集合总和需归零。测试每个状态变更和删除，注意函数返回行与触发时机。官方分值为插1、改2、删1、计算1。

INSERT adds qualifying NEW contribution; DELETE removes qualifying OLD contribution; UPDATE removes OLD and adds NEW, or re computes affected totals. Empty sums become zero. Test every transition/deletion and return the appropriate trigger row. The stated marks are insert 1, update 2, delete 1 and calculation 1.
